# Projeto Nova-Web - UI/UX Design

## Aula 09: UX de Tabelas de Dados e Telas de Perfil

### 1. Pesquisa Teórica - UX para Tabelas Corporativas

#### Alinhamento de Dados

* **Textos:** devem ser alinhados à esquerda para facilitar a leitura.
* **Números e valores monetários:** devem ser alinhados à direita, facilitando a comparação entre valores.
* **Status e ações rápidas:** podem ser centralizados para facilitar a identificação e utilização.

#### Filtros e Busca

* O campo de pesquisa principal deve ficar localizado na parte superior da tabela, permitindo que o usuário encontre rapidamente as informações.
* Os filtros avançados podem ser agrupados em menus suspensos (dropdowns), evitando ocupar muito espaço na tela.
* Os filtros devem possuir nomes claros para que o usuário entenda facilmente sua função.

#### Hierarquia Visual

* Tabelas extensas podem utilizar cabeçalhos fixos (sticky header), mantendo os nomes das colunas visíveis durante a rolagem.
* A alternância de cores entre as linhas (zebra striping) pode facilitar a leitura dos dados.
* Bordas sutis e espaçamentos adequados também ajudam a separar as informações.
* O cabeçalho da tabela deve possuir destaque visual em relação às linhas de dados.

#### Telas Desenvolvidas

**1. Perfil de Usuário**

A tela de perfil apresenta informações do usuário, incluindo:

* Avatar;
* Nome completo;
* E-mail;
* Cargo;
* Dados pessoais;
* Formulário para edição;
* Nível de permissão;
* Botão para salvar alterações.

**2. Área de Consulta (Tabela)**

A tela de consulta apresenta uma tabela de usuários contendo:

* Nome;
* E-mail;
* Cargo;
* Status;
* Busca;
* Ordenação;
* Paginação;
* Ação de editar;
* Ação de excluir.

A tabela foi organizada para facilitar a visualização e consulta dos dados, utilizando alinhamento adequado, cabeçalho destacado e espaçamento entre as informações.

### 3. Objetivo da Interface

O objetivo do projeto é criar uma interface corporativa simples e organizada, permitindo que os usuários consultem informações e gerenciem seus dados de maneira rápida.

As decisões de UI/UX foram pensadas para facilitar a leitura das tabelas, encontrar informações através da busca e realizar ações como editar ou excluir registros.

### 4. Conclusão

A utilização de boas práticas de UX em tabelas corporativas melhora a organização das informações e facilita o trabalho dos usuários.

O alinhamento dos dados, os filtros, a busca, a paginação e a hierarquia visual ajudam a tornar a interface mais clara e fácil de utilizar.

No protótipo desenvolvido no Figma, esses conceitos foram aplicados nas telas de perfil de usuário e consulta de dados.
