# Sistema Web - NovaWeb Studio

## Descrição

Este projeto foi desenvolvido para a Situação de Aprendizagem
da NovaWeb Studio.

O sistema possui uma tela de login, uma página de perfil
do usuário e uma página de consulta de usuários.

## Funcionalidades

- Tela de login.
- Perfil do usuário.
- Consulta de usuários.
- Pesquisa na tabela.
- Navegação entre páginas.
- Layout responsivo.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto

- index.html
- perfil.html
- consulta.html
- css/style.css
- js/app.js
- img/logo.svg
- img/avatar.svg

## Como executar

1. Abrir a pasta no Visual Studio Code.
2. Abrir o arquivo index.html.
3. Executar com Live Server.
4. Informar um e-mail e uma senha.
5. Navegar pelas páginas do sistema.

## Observação

O login é demonstrativo e não utiliza banco de dados.
Os usuários da tabela são exemplos.
